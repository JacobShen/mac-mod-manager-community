# Security policy / 安全政策

Do not disclose a suspected vulnerability in a public issue. Email
[support@macmodmanager.app](mailto:support@macmodmanager.app) with a concise
description, affected version, reproduction steps, and impact. Do not attach
game files, Mods, license keys, payment records, credentials, or unrelated
personal data.

请勿通过公开 Issue 披露疑似安全漏洞。请发送邮件到
[support@macmodmanager.app](mailto:support@macmodmanager.app)，说明受影响版本、
复现步骤和可能影响。请勿附加游戏文件、Mod、许可证密钥、付款记录、账号凭据或
无关个人信息。

Supported versions / 当前安全维护版本：

| Version | Supported |
| --- | --- |
| Latest notarized release / 最新已公证版本 | Yes / 是 |
| Older builds / 更早构建 | Best effort / 尽力支持 |
