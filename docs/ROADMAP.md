# Support roadmap / 支持路线图

Only a game marked **Released** is part of the current compatibility promise.
Every new module receives separate Mac resource auditing, conversion tests and
deployment/rollback tests. Per-Mod real-game validation continues after release
where coverage is incomplete and is reported transparently in Known Issues.

只有标记为**已发布**的游戏才属于当前兼容承诺。每个新模块都必须分别完成 Mac
资源审计、转换测试和部署/回滚测试。若部分 Mod 的实机覆盖尚未完成，会在发布后
继续验证，并在已知问题中透明披露。

| Order | Game / 游戏 | Status / 状态 |
| ---: | --- | --- |
| 1 | Resident Evil 4 / 生化危机 4 | Released first / 首个发布 |
| 2 | Resident Evil 2 / 生化危机 2 | Released / 已发布 |
| 3 | Resident Evil 3 / 生化危机 3 | Planned / 计划中 |
| 4 | Resident Evil Village / 生化危机 Village（村庄） | Planned / 计划中 |
| 5 | Resident Evil 7 biohazard / 生化危机 7 | Planned last in V1 / V1 最后 |

If CAPCOM releases future native Mac versions of Resident Evil 9,
Resident Evil CODE: Veronica, or other relevant games, compatibility work will
begin as soon as a legally obtained public build can be independently verified.

如果 CAPCOM 后续发布《生化危机 9》《生化危机 CODE: Veronica（维罗妮卡）》
或其他相关游戏的 Mac 原生版本，我们会在能够合法取得并独立验证公开正式版后，
第一时间启动兼容评估。
