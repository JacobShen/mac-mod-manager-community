# 安装指南

1. 从 [macmodmanager.app](https://macmodmanager.app/zh/) 或对应的 GitHub Release
   下载当前 DMG。
2. 对比两个发布渠道显示的 SHA-256。
3. 打开 DMG，将 **Mac Mod Manager** 拖入“应用程序”。
4. 启动软件。应用已通过 Developer ID 签名和 Apple 公证；如果下载文件校验值
   不一致，请勿绕过 macOS 安全警告。
5. 软件会自动寻找已支持的 Mac 原生游戏。未找到时，请先安装游戏，或在设置中
   手动选择游戏 App。
6. 导入 Mod 文件夹、ZIP、RAR 或 7z，检查分析结果后再启用。

Mac Mod Manager 不负责安装游戏，也不会提供游戏或 Mod 文件。确认导入结果前，
建议保留原始 Mod 下载文件。
